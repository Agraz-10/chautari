# CHAUTARI

### A Modern Café Inspired by Nepal

CHAUTARI is a modern café website inspired by the traditional Nepali concept of a *chautari* — a place where people pause, rest, meet, and share stories.

The project combines a warm contemporary café aesthetic with subtle elements inspired by Nepali culture, creating a digital experience centered around coffee, food, community, and conversation.

## Concept

The idea behind CHAUTARI is simple: a café should be more than a place to have coffee.

It should be a place to slow down, spend time with others, have meaningful conversations, and enjoy small moments.

The website reflects this idea through spacious layouts, warm colors, editorial typography, atmospheric imagery, and simple interactions.

## Design Direction

CHAUTARI follows a warm and welcoming visual identity built around:

- Terracotta and earthy tones
- Warm beige and cream backgrounds
- Sage green accents
- Editorial serif typography
- Natural food and café photography
- Spacious and clean layouts
- Subtle hover interactions
- Responsive design for different screen sizes

The design intentionally avoids an overly complex interface and focuses on creating a calm, premium café atmosphere.

## Brand Philosophy

**Good Coffee. Good Food. Good Company.**

CHAUTARI is built around the belief that simple things can create meaningful moments.

From a quiet morning coffee to an afternoon conversation with friends, the website represents the café as a place where people can pause and stay awhile.

## User Experience

The website focuses on making the experience simple and intuitive.

Navigation is kept clear across desktop and mobile layouts, while responsive design allows the experience to adapt naturally to smaller screens.

The mobile navigation uses a lightweight CSS-based hamburger menu, keeping the interface functional without unnecessary JavaScript.

## Visual Identity

The visual language combines contemporary café design with a subtle connection to Nepal.

Terracotta represents warmth and character, beige and cream create a relaxed atmosphere, while sage green adds a natural element inspired by Nepal's landscapes.

Large serif headings and carefully spaced layouts give the website an editorial character while maintaining readability and simplicity.

## Technologies

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Project Goal

The goal of CHAUTARI is to create a polished and responsive café website that communicates a strong brand identity while providing a simple and enjoyable browsing experience.
